# KCM v0.3 검증 보고

## 수행 환경과 방법
- Node.js 22.16.0 / TypeScript 5.8.3 / 설치된 Chromium.
- npm install 1회 시도: 레지스트리 DNS EAI_AGAIN으로 실패. 재시도 반복하지 않음.
- 이전 HTML의 MIT React 런타임에 최신 src/ 21모듈을 결합해 독립 HTML 생성.
- file:// 직접 열기 차단(ERR_BLOCKED_BY_ADMINISTRATOR)으로 새 브라우저 페이지에 HTML을 DOM 주입.
- 이 검증은 실제 사용자 PC의 npm/Vite 실행 또는 로컬 파일 더블클릭 검증이 아닙니다.

## 미검증/제한
전체 React 타입 검사/Vite 빌드/Vite 서버/Windows 로컬 파일 실행은 별도 필요합니다.
브라우저·OS별 글꼴 렌더링은 다를 수 있으며 폰트 파일은 배포하지 않습니다.
인증·DB·n8n·Retell·외부 API를 연결하거나 테스트하지 않았습니다.
로그아웃 버튼은 실제 세션을 종료하지 않는 UI 예시입니다.
