# v0.2 변경 내역

기준: 이 대화에서 제공한 KCM_web_starter_v0.1.zip.
사용자 PC의 파일을 원격으로 읽거나 수정하지 않았습니다.

## 변경
- 홈을 단독 메뉴로 분리, 대분류를 고객관리/상담업무/매장관리로 변경.
- 사용자 요청 표기에 맞게 메뉴 이름 정리.
- 상품관리 메뉴와 4개 탭, 요금제 내부 자사/타사 전환.
- 운영 정보를 매장관리로 교체, 매장/직원 2개 탭.
- 홈의 기존 연동 준비 안내 아이콘은 프로토타입 안내 모달로 연결.
- 가상 매장 5곳·우리 매장 직원 3명·리뷰 샘플 추가.
- 메뉴/샘플 테스트 10개 추가(합계 28개).
- 개발 지침과 미리보기·검증 기록 갱신.

## 유지
기존 홈 본문·폰트·색상, 예약/브리핑/재고의 샘플 동작, 프레임워크와 의존성 목록.
기존 CSS를 그대로 두고 신규 페이지·내비게이션 스타일만 추가했습니다.

## 추가하지 않음
DB·n8n·Retell 연동, 실제 상품 조회/검색/등록/수정/비교,
직원 성향 분석/매칭, 실제 리뷰 수집, 발송·배포.
