- Retell AI의 경고 응답은 KCM 분석 횟수의 입력이 아닙니다. Retell transcript → Backend `text-risk` → SSE → 직원 화면을 유지합니다. n8n은 이 실시간 탐지를 수행하지 않습니다.
- `local-text-rules-v4`는 USER만 분석합니다. Agent 경고·욕설 인용·소리를 낮추라는 응답은 위험 횟수, 대상 문맥, 고성에 사용하지 않습니다. 고성은 기존 마이크 RMS/audio 결과만 사용합니다.

- 사람/공격 문맥: 너·직원·상담사 등 대상 또는 찾아가서/가서와 팬다·팰 거야·패버린다·때린다·때릴 거야·패준다를 결합합니다. 두들겨 팬다와 직원도 가만 안 둘 거야도 검사합니다. 독립적인 `팬다` 한 단어는 광범위하게 분류하지 않습니다.
- 최근 USER 미완성 발화 최대 2개, 발화당 최대 120자만 대상으로 합니다. 확인 가능한 start_sec 간격은 30초 이내이고, 현재 행동 발화의 앞 160자에서만 경계를 넘는 위협을 찾습니다. 시각이 없으면 turn/글자 수 제한을 적용합니다.
- 미완성 대상/행동으로 끝나지 않은 문장, 완료된 일반 문장, 인용·신고 문맥은 연결하지 않습니다. Agent가 끼어들어도 Agent 내용은 연결하지 않습니다. 전체 transcript를 합쳐 다시 분석하지 않습니다.
- 독립 탐지와 연결 탐지가 같은 행동을 찾으면 1회만 집계합니다. 연결된 위협 배지는 실제 현재 USER 행동 turn에 귀속하고, 근거에는 그 발화의 행동 부분만 담습니다. reason에 이전 USER 미완성 문맥 사용을 표시합니다.
- 이전/current의 제한된 USER 문맥 fingerprint를 비교합니다. 앞 turn 내용·역할·시각 정정/삭제가 바뀌면 종속 결과도 재평가합니다. 동일 turn 결과 교체, 현 목록 합계 재구성, 변하지 않은 결과 cache 재사용을 유지합니다. 외부 SSE/분석 DTO 필드는 추가하지 않았습니다.
- 기존 인용·신고·부정 guard를 유지하고, profanity/threat에 한해 `팬다는 건/게/것은 아닙니다`, `팬다는 얘기를 했어요` 같은 명시 부정·전언을 보완했습니다. `팬다는 건 결정됐습니다`라는 실제 단정은 탐지합니다. 비난·선정 규칙은 변경하지 않습니다.

`call-risk-v4`, 통화별 독립 0점 출발, 최대 99점입니다. 고객 누적 정책을 추가하지 않습니다.
