## 실제 변경

- 상품관리를 조회·비교 화면으로 보강했다. 중립적인 상담 참고 요금제 6건, 결합 3건, 혜택 2건을 제공하며 제품명·용량·색상은 기존 재고 자료에서 투영한다. 검색 결과가 없으면 이전 상세를 표시하지 않는다. 자사·타사 비교는 최대 3개이며 제외/전체 제외가 동작한다. 공식 상품이나 실제 가입 조건으로 표시하지 않는다.
- 기존 준비 중/확인 필요 예약 브리핑에서 ‘예약 상세 보기’를 기존 상세 모달과 연결했다. 예약 상태나 브리핑 데이터는 변경하지 않는다.
- 320/390px 상품 탭을 2열로 배치하고 좁은 모달의 긴 버튼을 줄바꿈했다. 기존 직원 화면의 큰 배치·색상·폰트·카드·8메뉴는 유지한다.
- 지원과 사후관리 버튼·기록은 기존 상태 변경 함수를 그대로 사용한다. 발송을 ‘안내 처리’로 표현하고 실제 문자 전송으로 표시하지 않는다.
- 고객 통화 페이지의 진단 details는 `hidden`/`aria-hidden`으로 일반 화면과 키보드/접근성 트리에서 숨겼다. 내부 컨트롤러·마이크·reporter·종료 snapshot 코드와 핸들러는 유지한다. 기존 오류를 고객용 안내로 표시한다.
- 고정 참고 자료의 표시 문구만 `uiText`로 정리한다. 원본 ID·분석 수치·저장 데이터와 직원이 입력하는 상담 결과·지원 메모·후속 메시지·실제 전문은 변경하지 않는다.

## 의도적으로 유지한 안내

- 상품은 공식 상품정보가 아닌 상담 비교 자료라는 작은 안내: 요금·사양을 공식 사실로 오인하지 않도록 한다.
- 지원·후속 안내는 외부 알림/문자를 전송하지 않는다는 작은 안내: 실제 처리 범위를 구분한다.
- 결과 입력/처리 기록의 새로고침 초기화, 실시간 기록의 조회 범위: 기록 손실·보관 범위를 알린다. 홈 중심의 기술 설명은 줄였다.
- n8n 수신 응답과 DB 저장 완료의 구분, 음성 미측정 시 최종 점수 보류: 미검증 저장 성공·잘못된 0점으로 표시하지 않는다.
- 로그인 없이 이용하는 화면이라는 로그아웃 안내: 없는 로그인 세션을 종료했다고 표시하지 않는다.
- 재고 수량 참고 및 담당자 확인 안내: 팀원 코드 병합 전 실제 대여·반납으로 오인하지 않도록 한다.
