모바일 또는 높이가 560px 이하인 매우 낮은 데스크톱 화면은 메뉴 버튼을 사용합니다.

## 데이터 편집 위치
`src/data/workspaceMockData.ts`에 현재 매장과 직원 예시를 한 곳에 모았습니다.
상단/좌측 매장명, 예약 담당자, 직원정보의 현재 사용자 표시가 같은 기준을 사용합니다.

```ts
employee: {
  name: '이소현',
  givenName: '소현', // 성과 분리된 이름. 외자는 '준'처럼 1글자 입력
  position: '점장',
  gender: 'female', // 'male' | 'female' | 'unspecified'; 이름에서 추정하지 않음
  reviewScore: 4.7,
}
```

위 코드는 설명용 발췌입니다. 실제 객체에는 id·전문분야·상담 스타일도 포함됩니다.
`givenName`은 최대 두 글자까지 표시하며 외자 이름은 그대로 한 글자를 표시합니다.
복성에도 전체 이름을 기계적으로 자르지 않습니다. UI 모델이지 Supabase 스키마가 아닙니다.

## 검증 결과
- TypeScript 5.8.3로 순수 로직·메뉴·샘플·프로필 테스트 **40개 통과**.
- TS/TSX 21개 모듈의 문법 변환 오류 없음.
- Chromium에 HTML을 주입해 UI 점검 **41항목 통과**.
- 12개 화면 크기에서 홈의 가로 넘침, 고정 메뉴의 잘림, 프로필 창 위치를 확인.
- 남성 외자 프로필은 테스트 전용 데이터로 검증했고 배포본은 여성 ‘소현’입니다.
- JavaScript/콘솔 오류 및 외부 네트워크 요청 없음.

**미검증:** 전체 React 타입 검사·Vite 빌드·개발 서버·사용자 Windows에서의 실행.
생성 환경 npm 레지스트리 DNS가 실패해 전체 의존성을 설치하지 못했습니다.
file:// 직접 열기도 제한되어 DOM 주입 방식으로 검증했습니다.
HTML은 v0.2의 MIT 라이선스 React 런타임과 최신 원본을 묶었습니다.
상세 결과는 `docs/QA_REPORT.md`, `docs/qa-results-v0.3.json`을 확인하세요.

## 제한
매장명은 사용자 지정 표시값이고 직원·평점·리뷰·고객·재고는 UI 예시입니다.
실제 매장·사용자·평점의 정확성을 검증한 데이터가 아니며 KT 공식 운영 서비스가 아닙니다.
상단·좌측에서 요청한 안내만 제거했고 기존 본문·푸터의 데이터 안내는 유지했습니다.
인증, 권한, 실제 상품/리뷰 조회, API/DB/문자 발송 기능은 없습니다.
새로고침하면 메모리 상태는 초기화됩니다. 실제 개인정보나 비밀 키를 넣지 마세요.
